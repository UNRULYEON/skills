# Investigation

1. Treat this as read-only. Answer the question; don't make changes along
   the way.
2. Trace every claim to evidence — the actual code, actual logs, actual
   history, actual running behavior — not memory or assumption.
3. If the question has sub-parts, answer and confirm one before moving to
   the next rather than assembling a single unverified chain.
   ([sequence into verifiable units](../principles.md#sequence-into-verifiable-units))
4. Report the trail, not just the conclusion: enough that someone else could
   check the reasoning without redoing the investigation.
